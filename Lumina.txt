# 📘 LUMINAA - COMPLETE PLATFORM BLUEPRINT

## 🎯 EXECUTIVE SUMMARY

**Platform Name:** Luminaa (Light in Learning)

**Mission:** Democratize accessible education for neurodivergent children in India through AI-powered adaptive learning.

**Target Users:** 
- 10-13 year old students with Dyslexia, ADHD, and Low Vision
- Parents seeking affordable special education solutions
- Teachers managing inclusive classrooms

**Core Innovation:** Single unified platform that adapts itself to each child's disability profile, rather than separate apps for each condition.

# 📚 COMPLETE MODULE BREAKDOWN

## MODULE 1: AUTHENTICATION & ONBOARDING

### A. Multi-Role Login System
- **Students:** 4-digit PIN + visual keypad (no password memory needed)
- **Parents/Teachers:** Email/Password + Google OAuth
- **Visual Design:** Indian Night theme with animated Diya lamp

### B. Profile Creation (5-Step Wizard)
**Step 1: Welcome & Avatar**
- Choose animal avatar (elephant, tiger, peacock, dolphin, owl)
- Friendly introduction animation

**Step 2: Basic Info**
- Name, Age (10-13), Grade (5-8)
- Language preference (English, Hindi, Marathi)

**Step 3: Disability Selection**
- Visual cards with descriptions:
  - ✅ **Dyslexia** - "Letters sometimes swap or dance?"
  - ✅ **ADHD** - "Hard to sit still or focus for long?"
  - ✅ **Low Vision** - "Need bigger text or high contrast?"
- Multi-select allowed (comorbidity support)

**Step 4: Learning Preferences**
- Audio narration: ON/OFF
- Font size: Small/Medium/Large/X-Large
- Color scheme: Default/High Contrast/Dyslexia Friendly
- Game mode: ON (prefer games over text)

**Step 5: Summary & Celebration**
- Review all choices
- Animated confetti on completion
- "Your learning space is ready!" message

### B. Lesson Delivery System

**Each lesson includes:**

1. **Introduction (2 min)**
   - Animated video or visual hook
   - Learning objectives in simple language

2. **Main Content (7-10 min)**
   - **Original Text** (for reference)
   - **AI-Simplified Text** (Groq API - dyslexia-friendly)
   - **Audio Narration** (Browser TTS)
   - **Visual Aids** (diagrams, animations, infographics)
   - **Interactive Elements** (click to reveal, drag-and-drop)

3. **Practice Activity (5 min)**
   - Mini-quiz (3-5 questions)
   - Interactive exercise
   - OR embedded game

4. **Summary (1 min)**
   - Key takeaways
   - Badge earned (if assessment passed)

**Accessibility Options (Always Available):**
- 🔊 Play/Pause audio
- ⏩ Speed control (0.7x - 1.3x)
- 🎨 Toggle high contrast
- 📏 Adjust font size
- ⏸️ Focus timer (ADHD - 7 min default)

---

### C. Parent Content Upload System

**Workflow:**

1. **Upload PDF/Image**
   - Drag-and-drop interface
   - Supports: PDF, JPG, PNG

2. **AI Processing (Backend Cloud Function)**
   - OCR extraction (Tesseract.js)
   - Text simplification (Groq API)
   - Audio generation (Browser TTS)
   - Chunking for ADHD (5-min segments)
   - High-contrast version for low vision

3. **Adaptive Versions Generated**
   - Dyslexia version (simplified + audio)
   - ADHD version (chunked + timers)
   - Low vision version (large text + high contrast)

4. **Assign to Child**
   - Set deadline (optional)
   - Add parent note
   - Notification sent to student

**Example:**
Parent uploads Grade 6 Math worksheet PDF → System creates 3 adaptive versions → Child accesses based on their profile → Parent sees completion status

#### **2. CUSTOM-BUILT GAMES (Phaser.js)**

**Game 1: Word Jump** (Dyslexia Focus)
- **Mechanic:** Letters fall from top, student drags them to form words
- **Dyslexia Mode:**
  - Slower fall speed (3 sec per letter)
  - OpenDyslexic font
  - Audio hint on hover
  - Pastel background (#FFFACD)
- **ADHD Mode:**
  - Faster gameplay (1.5 sec)
  - Instant sound effects
  - Streak counter visible
  - Quick rewards every 5 words
- **Low Vision Mode:**
  - Large letters (64px)
  - High contrast (yellow on black)
  - Audio announcement of each letter

**Scoring:**
- Correct word = 10 points
- 5-word streak = 50 bonus
- Level up every 100 points

## MODULE 6: AI-POWERED FEATURES

### A. Text Simplification (Groq API)

**Before (Original NCERT):**
> "Photosynthesis is the process by which green plants and some other organisms use sunlight to synthesize foods with the help of chlorophyll, converting carbon dioxide and water into glucose and oxygen."

**After (AI Simplified):**
> "Plants make their own food. They use sunlight, water, and air. Green leaves do this magic. They make sugar and release oxygen. We breathe that oxygen."

**API Call:**
```javascript
const simplified = await groqAPI.simplify(originalText, {
  targetAge: 11,
  maxWordsPerSentence: 12,
  avoidWords: ['synthesize', 'chlorophyll', 'carbon dioxide']
});
```

---

### B. Behavioral Analytics

**Tracked Metrics:**
- Session duration
- Click patterns
- Audio usage rate
- Game vs lesson preference
- Time of day performance

**AI Recommendations:**
```
IF (audioEngagement > 70% AND gameCompletionRate > 80%)
  → Recommend more game-based learning

IF (focusDuration drops after 7 minutes)
  → Shorten lessons to 5 min chunks
  → Add break reminders

```

### C. Smart Content Recommendations

```
1. Analyze weak subjects (accuracy < 60%)

3. Match to preferred format (game/lesson/video)
4. Schedule during optimal time window
```

**Example Output:**
